# Radio

Control de selección exclusiva dentro de un grupo. Al compartir el mismo `name`, los radios son mutuamente excluyentes: seleccionar uno deselecciona el resto. Utiliza el elemento `<input type="radio">` nativo — no necesita motor de conducta, ya es accesible por defecto.

## Superficie oscura

La marca es tinta: borde y punto pasan de prusia a blanco (`surface-dark-border-color`, `surface-dark-dot-color`), y el anillo de foco con ellos. El deshabilitado se queda en `grey-light` en las dos superficies: un control apagado está exento de contraste.

<Canvas of={RadioStories.SuperficieOscura} />

## Dentro de un grupo

Un radio suelto no es excluyente de nada: lo que agrupa las opciones es compartir `name`. Esa
parte —y saber cuál está marcada— la lleva `RadioGroup`, y `Radio` la lee de él: dentro de un grupo
no hay que pasar `name`, `checked`, `size` ni `disabled`. Lo que se pase a mano manda sobre el
grupo.

## Uso

```tsx
import { Radio } from '@studiolxd/brand/radio';

<Radio name="plan" value="basico"   aria-label="Básico"    defaultChecked />
<Radio name="plan" value="pro"      aria-label="Pro" />
<Radio name="plan" value="empresa"  aria-label="Empresa" />
```

Todos los radios del mismo grupo deben compartir el atributo `name`. El `value` identifica la opción seleccionada al enviar el formulario. Para uso controlado, pasa `checked` y `onChange`.

## Objetivo de puntero

El dibujo mide 20px (16px en `sm`), pero el **área que responde al puntero** llega siempre
a 24×24, el mínimo de WCAG 2.5.8: la extiende una capa invisible centrada
(`radio.target-size`, que apunta a `--size-target-min`) que no ocupa sitio en la maqueta ni
engorda la marca.
