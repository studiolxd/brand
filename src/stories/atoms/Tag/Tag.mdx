# Tag

Etiqueta en forma de píldora para clasificar o categorizar contenido. Tiene cinco variantes de color de marca (`primary`, `accent-1`, `accent-2`, `support-1`, `support-2`) y cinco variantes semánticas de estado (`neutral`, `info`, `warning`, `success`, `danger`). Se usa en tarjetas, listados de proyectos, filtros y estados. `neutral` es el único tag con fondo gris — no hay una variante "default" separada.
