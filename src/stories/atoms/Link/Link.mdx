# Link

Enlace de texto. No tiene color propio: es texto del color del texto, y lo que dice «esto se pulsa» es la **línea** bajo el enlace —un borde a distancia del texto, no `text-decoration`, para que cubra también un icono— que desaparece en hover. Así funciona dentro de un párrafo, en un pie, sobre superficie oscura, sin depender del color.

## La base viste a todos los enlaces

La cara la pone `brand.css` sobre cualquier `<a>`, sin clases: el HTML de un CMS, un markdown o el `<Link>` de Next.js salen iguales. El componente solo añade API: `external` (nueva pestaña con `rel="noopener noreferrer"`) y el reenvío de `ref` y atributos.

<Canvas of={LinkStories.Externo} />

## Botón con cara de enlace

`Button variant="text"` toma su cara de estos mismos tokens (`button.text.*` → `link.*`): una acción que no navega (abrir un panel, deshacer) pero que se lee como un enlace. Y al revés, `Button href` es un `<a>` con cara de botón. Semántica según lo que hace; cara según lo que pide la maqueta.
