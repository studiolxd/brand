# ColorPickerField

El `ColorPicker` como campo de formulario: etiqueta, disparador, ayuda y error, con el mismo ritmo
que el resto de campos. El valor, el panel y su accesibilidad están en `ColorPicker`.

<Canvas of={ColorPickerFieldStories.PorDefecto} />

## Etiqueta

Siempre hay etiqueta (`label`), enlazada al disparador, y **por defecto se ve**. La etiqueta
nombra el disparador y también el panel que abre. Sin `id`, el campo genera uno con `useId`.
Como en cualquier botón etiquetado, pulsar la etiqueta abre el panel.

<Canvas of={ColorPickerFieldStories.EtiquetaOculta} />

## Ayuda y error

`helperText` describe; `errorMessage` avisa (`role="alert"`) y pone el disparador en error por sí
solo. Los dos quedan enlazados por `aria-describedby`, junto al valor actual.

<Canvas of={ColorPickerFieldStories.ConAyuda} />
<Canvas of={ColorPickerFieldStories.ConError} />

## Obligatorio

El disparador es un botón, y un botón no admite `aria-required`. Con `required`, lo obligatorio lo lleva el **grupo** que envuelve el campo: `role="group"`, nombrado por la etiqueta y con `aria-required="true"`. El `<form>` no se envía sin color: el campo que sincroniza el hex pasa a llevar `required` y, cuando el navegador lo enfoca para avisar, devuelve el foco al disparador.

## Disparador propio

`trigger` y `anchor` llegan al `ColorPicker` tal cual (§ «Disparador propio» y «Anclado sin
disparador» de `ColorPicker`). Con `trigger`, la etiqueta **sigue nombrando** el elemento propio
(`aria-labelledby` gana a su propio `aria-label`), la ayuda y el error lo describen junto al valor,
el error le pone `aria-invalid` y el `ref` del campo le llega. `size` no viaja a él: su talla es la
que le dé quien lo pinta. `anchor` sin `trigger` deja el campo sin disparador, así que en un
formulario no tiene sentido.

## Con react-hook-form

El contrato es `value` / `onValueChange` + `name` + `ref` al disparador, no el spread del `field`.
El `name` monta un input oculto con el hex para el envío nativo.

```tsx
<FormField
  control={form.control}
  name="acento"
  render={({ field, fieldState }) => (
    <ColorPickerField
      ref={field.ref}
      name={field.name}
      label="Color de acento"
      value={field.value}
      onValueCommitted={field.onChange}
      errorMessage={fieldState.error?.message}
    />
  )}
/>
```
