# Pagination

Componente de paginación controlado. Muestra controles de navegación (Anterior / páginas / Siguiente) con ellipsis automático. Soporta de forma opcional el recuento de resultados y el selector de registros por página.

## Por defecto

10 páginas, página activa resaltada, ellipsis cuando hay más páginas de las que caben en la ventana.

La prop `showTotal` añade el texto "X resultados" antes de los controles.

Cuando se pasa `onPageSizeChange`, aparece un `Select` con las opciones de página. Las opciones por defecto son 10, 20, 50, 100 y Todos; se pueden personalizar con `pageSizeOptions`.

## Integración con router (hrefBuilder)

Cuando los números de página deben ser enlaces reales (para SEO, SSR o comportamientos nativos del navegador como cmd+click), se pasa la prop `hrefBuilder`.

```tsx
import { Pagination } from '@studiolxd/brand';

<Pagination
  total={200}
  page={currentPage}
  pageSize={10}
  hrefBuilder={(p) => `/proyectos?page=${p}`}
  onPageChange={(p) => router.push(`/proyectos?page=${p}`)}
/>
```

Sin `onPageChange`, la navegación ocurre únicamente mediante el href nativo.

## Internacionalización de las etiquetas

Todos los textos que el componente emite por su cuenta —los `aria-label` de los controles y el
sumario de `showTotal`— están en **castellano por defecto**. Una aplicación multiidioma debe pasar
sus propias traducciones; si no lo hace, un usuario de lector de pantalla en inglés o alemán oirá
"Página 3".

| Prop | Default | Dónde aparece |
| --- | --- | --- |
| `ariaLabel` | `"Paginación"` | `aria-label` del `<nav>` |
| `pageLabel` | `` (page) => `Página ${page}` `` | `aria-label` de cada botón/enlace de página |
| `previousLabel` | `"Página anterior"` | `aria-label` del control anterior |
| `nextLabel` | `"Página siguiente"` | `aria-label` del control siguiente |
| `pagesGroupLabel` | `"Páginas"` | `aria-label` del `role="group"` de los controles |
| `pageSizeLabel` | `"Registros por página"` | `aria-label` del `Select` de registros por página |
| `totalLabel` | `` (total) => `${total} resultados` `` | texto del sumario cuando `showTotal` |

```tsx
const t = useTranslations('pagination');

<Pagination
  total={200}
  page={currentPage}
  pageSize={10}
  showTotal
  onPageChange={setPage}
  ariaLabel={t('label')}
  pageLabel={(p) => t('page', { page: p })}
  previousLabel={t('previous')}
  nextLabel={t('next')}
  pagesGroupLabel={t('pages')}
  pageSizeLabel={t('pageSize')}
  totalLabel={(n) => t('total', { count: n })}
/>
```

Las etiquetas de las opciones del selector de registros por página (incluida `"Todos"`) no son
props de texto: se traducen pasando `pageSizeOptions` con los `label` ya traducidos.

La convención completa (qué componentes tienen props de texto, cómo se nombran, cómo se traducen
fechas) está en **Foundations › Internacionalización**.

## Accesibilidad

- Todos los botones llevan `type="button"`: dentro de un `<form>`, el default nativo
  (`submit`) enviaría el formulario al cambiar de página.
- Lo que no lleva a ningún sitio no es un enlace: la **página vigente** y las flechas sin
  página a la que ir se pintan como `<button>` (con `aria-current="page"` la primera,
  deshabilitado las segundas), nunca como un `<a>` sin `href` — que no es enfocable por
  teclado ni se anuncia como enlace. Con `hrefBuilder`, el resto sí son enlaces de verdad.
- El subrayado del botón en hover usa `pagination.btn-hover-underline-width`, un token propio —
  no `link.underline-width` — porque el botón de página no es un `Link`, aunque comparta la misma
  técnica visual (borde inferior, no `text-decoration`).
- `btn-disabled-color` (`grey-dark`) está exento de la regla «todo texto va en prusia o
  grey-darkest»: es un control deshabilitado, y `grey-dark` es justo el rol reservado para
  controles deshabilitados e iconos de acción secundarios.
