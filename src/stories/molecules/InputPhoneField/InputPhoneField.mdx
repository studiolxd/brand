# InputPhoneField

El `InputPhone` como campo de formulario: etiqueta, selector de país, número, ayuda y error, con el mismo ritmo que el resto de campos. Es el que se usa en formularios; el átomo suelto, solo fuera de ellos.

<Canvas of={InputPhoneFieldStories.PorDefecto} />

## Etiqueta

Siempre hay etiqueta (`label`), enlazada por `id` al `<input>` del número —no al selector de país, que tiene su propio nombre accesible (`countryLabel`)—. Sin `id`, el campo genera uno con `useId`.

<Canvas of={InputPhoneFieldStories.EtiquetaOculta} />

## Ayuda y error

`helperText` describe; `errorMessage` avisa (`role="alert"`) y pone el control en error por sí solo —`error` sirve para marcarlo sin mensaje—. Los dos quedan enlazados por `aria-describedby`, y el error también por `aria-invalid`.

<Canvas of={InputPhoneFieldStories.ConError} />

## País

`defaultCountry` decide el prefijo con el que arranca el campo (`ES` por defecto). El valor que sale por `onChange` va siempre en formato E.164 (`+34600123456`), independientemente de cómo se escriba.

## Tallas

`size` viaja al control: mide 32, 40 o 48, las tallas del sistema.

## Con react-hook-form

`onChange` entrega el número ya normalizado (E.164), no el evento: se enchufa directo a `field.onChange`. El `ref` llega al `<input>` del número, así que react-hook-form puede enfocarlo al fallar la validación.

```tsx
<FormField
  control={form.control}
  name="telefono"
  render={({ field, fieldState }) => (
    <InputPhoneField
      ref={field.ref}
      name={field.name}
      value={field.value}
      onChange={field.onChange}
      onBlur={field.onBlur}
      disabled={field.disabled}
      label="Teléfono"
      errorMessage={fieldState.error?.message}
    />
  )}
/>
```

## Accesibilidad

- La etiqueta va enlazada por `htmlFor`/`id` al input del número.
- Los `id` de ayuda y error se derivan del del campo (`<id>-helper`, `<id>-error`) y llegan al control por `aria-describedby`, en ese orden.
- El mensaje de error se anuncia (`role="alert"`) y marca el control con `aria-invalid`.
- El selector de país es un `Select` de Base UI con su propia etiqueta (`countryLabel`, «País» por defecto).
