# DatePickerField

El `DatePicker` como campo de formulario: etiqueta, campo con la fecha escrita, ayuda y error, con el mismo ritmo que el resto de campos. Es el que se usa en formularios; el átomo suelto, solo fuera de ellos.

Para fecha **y** hora, el campo es `DateTimeField`; para solo hora, `TimeField`.

## Etiqueta

Siempre hay etiqueta (`label`), enlazada por `id` al campo, y **por defecto se ve**. Sin `id`, el campo genera uno con `useId`.

## Ayuda y error

`helperText` describe; `errorMessage` avisa (`role="alert"`) y pone el control en error por sí solo —`error` sirve para marcarlo sin mensaje—. Los dos quedan enlazados por `aria-describedby`, y el error también por `aria-invalid`.

## Valor y rango

El campo es **controlado**: `value` + `onChange`. El formato de la fecha mostrada sale de `Intl` con el `locale` (`es-ES` por defecto), no de una plantilla propia. `minDate`, `maxDate` y `disabledDates` acotan lo elegible.

## Con react-hook-form

El control es de Base UI, así que el contrato **no** es el spread del `field`: es `value` / `onChange` + `name` + `ref` al campo de texto. `onChange` entrega `Date | null` —vaciar el campo borra la fecha—, que es lo que guarda react-hook-form; el `name` monta además un input oculto con la fecha en `yyyy-mm-dd` **en el huso local** (no `toISOString()`, que es UTC y desplazaría un día) para el envío nativo.

```tsx
<FormField
  control={form.control}
  name="inicio"
  render={({ field, fieldState }) => (
    <DatePickerField
      ref={field.ref}
      name={field.name}
      value={field.value}
      onChange={field.onChange}
      onBlur={field.onBlur}
      disabled={field.disabled}
      label="Fecha de inicio"
      errorMessage={fieldState.error?.message}
    />
  )}
/>
```

## Accesibilidad

- La etiqueta va enlazada por `htmlFor`/`id` al campo de texto; quien abre el calendario es el botón del final, con nombre accesible propio.
- Los `id` de ayuda y error se derivan del del campo (`<id>-helper`, `<id>-error`) y llegan al control por `aria-describedby`, en ese orden.
- El mensaje de error se anuncia (`role="alert"`) y marca el control con `aria-invalid`.
- Meses y días del calendario salen de `Intl` con el `locale`: no son props de texto.
